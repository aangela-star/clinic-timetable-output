# 晉安 Facebook 門診發布手冊

文字操作指引，介面名稱可能不同；圖解待補。本區僅提供導引，不使用權杖、不會自動發文；尚未實際驗證 Facebook 介面。

1. 先核對診所、月份、本次經人工核准 PNG 與核准文字，確認都是本月晉安資料並已取得本次發布授權。

2. 開啟晉安專屬粉專 https://www.facebook.com/tainanrehab 。由具有粉專權限的人員登入，切換為晉安粉專身分，再核對粉專名稱確實是晉安，確認後才繼續。不要在個人頁面或另一間診所粉專操作。

3. 新增貼文或更換既有相片的本次操作尚未確認。以下是條件式草稿，不代表使用者已選定新增貼文。若本次經確認採用新增貼文，在晉安粉專尋找「建立貼文」（Create post）及「相片／影片」（Photos/video）。名稱與位置可能因裝置或版本不同；若缺少權限、找不到按鈕或無法確認身分，停止並請主管協助，不改到其他頁面發布。

4. 加入本次已核准的高解析度 PNG；若尚未備妥，回到既有門診表產生器預覽並下載，再核對檔案。輸入本月核准文字，不自行新增或猜測醫師、日期或時間。

5. 在 Facebook 預覽完整貼文，確認整張圖片不裁切、清楚可讀，診所、月份及文字正確；有疑問先停止並請主管確認。

6. 僅在本次新增貼文方式及內容均已確認後，由本次授權員工親自在 Facebook 手動發布一次。本區開啟連結不代表已發布。

7. 發布後回到 https://www.facebook.com/tainanrehab 檢查新貼文、圖片及文字是否正確；可能需要登入，不保證未登入也能查看。結果不明時先檢查既有貼文與貼文狀態，請主管協助，不重複發布或上傳。
